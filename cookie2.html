Cookies (Cookie2 — Home / last watched)

Problem statement

Title: Home page reads your name and saves last watched video

Like YouTube Home: you did not type your name again. The browser sent cookie user. Cookie2 also saves lastVideo=Java (last watched).

What you must do:

  1. Run Cookie1 first so cookie user exists.
  2. Open Cookie2. Print every cookie name = value. Greet the user. Add lastVideo=Java.
  3. Write complete Java and complete web.xml for Cookie2 only.

Sample output (same HTML Tomcat prints at http://localhost:8080/basic-servlets/Cookie2):

Home — last watched
user = Rahul
Welcome back Rahul
Saved last watched: Java Servlets (cookie lastVideo=Java), like YouTube remembers the last video.
Account cookies
