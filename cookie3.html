Cookies (Cookie3 — Account cookies)

Problem statement

Title: Account settings — list cookies on this browser

Like YouTube Settings: list what this site stored on this laptop. Cookie3 only reads. It does not create a cookie.

What you must do:

  1. After Cookie1 and Cookie2, open Cookie3.
  2. Print every cookie (user and lastVideo). After Forget me, user must disappear.
  3. Write complete Java and complete web.xml.

Sample output (same HTML Tomcat prints at http://localhost:8080/basic-servlets/Cookie3):

Account — cookies on this browser
user = Rahul
lastVideo = Java
