Cookie demo (like YouTube Remember me)

Type Rahul → Write. Type Sagar → Write. Read / Display all shows both (each name is its own cookie).

A cookie is known by its name only. Rahul is saved as u_Rahul and Sagar as u_Sagar, so two different names live together. Write Rahul a second time and the same u_Rahul box is used again — the value is written on top, no second copy is made, and no old name is deleted. Only setMaxAge(0) deletes.

Theory Run project Source

Each new name adds a cookie; the same name reuses its own cookie. Delete: type that name (Rahul) and click Delete selected cookie — only that one goes.
