Problem statement

Title: Remember me on this browser (YouTube-style cookie)

HTTP forgets you after each click. YouTube still says Continue as Rahul because the browser kept a small sticker: cookie user=Rahul. Password is never stored.

What you must do:

  1. POST display name Rahul to Cookie1. The page must show Continue as Rahul (cookie user=Rahul).
  2. Open Home (Cookie2). It greets Rahul without typing the name again, and saves last watched lastVideo=Java. Open Account cookies (Cookie3) and print both cookies.
  3. Open Forget me (CookieDelete). Then Cookie3 must no longer show user. Write all four classes and complete web.xml.

Sample output (same HTML Tomcat prints at http://localhost:8080/basic-servlets/Cookie1):

Continue as Rahul
This browser saved your name (cookie user=Rahul), like YouTube Remember me.
Password is not stored.
Open Home (last watched) | Forget me on this device
