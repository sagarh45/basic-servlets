Small project: WatchTube Remember me (like YouTube)

One real cookie project. Three steps must all work: WRITE → READ → DELETE → READ again (empty). Password is never stored. Cookie names: user and lastVideo=Java.

Theory Run project Source ICA journal

What this project does

YouTube still says Continue as Rahul because the browser kept a sticker. This page is that mini site.

  1. WRITE — Remember me as Rahul. Java addCookie saves user=Rahul and lastVideo=Java.
  2. READ — Open Home. You do not type the name again. Java getCookies() prints both values.
  3. DELETE — Forget me. Java setMaxAge(0) on the same names and path. Then READ must show both gone.
After WRITE then READ:
user = Rahul
lastVideo = Java
Welcome back Rahul

After DELETE then READ:
No lab cookies (user / lastVideo).
Forget me worked.
