This is a normal website — students open one https link. No Tomcat and no localhost on their phones or laptops.

Theory, ICA Practicals, Quiz, and Execute Online all run in the browser. Session login: java / servlet.

How you publish the link (once): go to app.netlify.com/drop, drag this folder basic-servlets onto the page. Netlify gives a public address such as https://random-name.netlify.app. Share that with the class. (GitHub Pages works the same way if you already use GitHub.)

If you open this folder on Tomcat port 8080, the original Java servlets still run. On the public website, Execute uses the same teaching steps in the browser.
