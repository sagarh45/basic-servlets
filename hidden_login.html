Problem statement

Title: Hidden form field login

The form posts login, password and a hidden session_id the student does not type. Login is java / servlet.

What you must do:

  1. POST to Valid. Hidden field session_id=054 must go with the form.
  2. If login is correct, forward to Welcome. Address bar stays /Valid.
  3. Welcome prints id:054 and Welcome java. Wrong password prints Incorrect LoginId/Password.

Sample output (same HTML Tomcat prints at http://localhost:8080/basic-servlets/...):

id:054
Welcome java
