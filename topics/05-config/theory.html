5. ServletConfig and ServletContext

Theory Lab Setup Index
Verified for Apache Tomcat 11.0.24 (Jakarta EE 11 / Servlet 6.1) + JDK 21+
Every program uses jakarta.servlet.* only. See Lab Setup.

This page is theory only: meaning, real-life examples, diagrams, functions (syntax + use + example) and complete code. Copy the journal problem statement from the ICA Practicals tab or from the program Source page.

A) Concept in simple English

Every page of a shopping mall website can print the same mall name: “Phoenix Mall”. That name belongs to the whole mall, not to one shop. One shop can also print its own manager name — that stamp belongs only to that shop. Mixing them is a common viva trap.

ServletConfig is data for one servlet (init-param inside that servlet in web.xml).

ServletContext is data for the whole application (context-param at the top of web.xml). Every servlet in basic-servlets can read it.

Both use a method named getInitParameter(name). The object you call it on decides which XML you read.

Picture it from daily life

One-line rule: Mall name is shared (ServletContext). One shop’s manager stamp is private (ServletConfig). Same method name getInitParameter — the object you call it on decides which drawer you open.

The story (mall name vs shop stamp)

Every shop notice, bill and offer can print:

“Phoenix Mall”

That name belongs to the whole mall. Change it once at the mall office and every shop’s page updates. In XML that is <context-param> named collegeName (this lab still uses that param name). You read it with getServletContext().getInitParameter("collegeName").

Now look at one shop only. The page also prints author = Student Name. That stamp belongs to this shop / this servlet, not to Cookie1 or ForwardServlet. In XML that is <init-param> inside this servlet. You read it with getServletConfig().getInitParameter("author").

If you ask Config for collegeName, you get null. If you put author as a context-param, every other program could read a value that is not theirs. That mix-up is a common viva trap.

What you will see

The result page prints two lines: shared name (context) and author (this servlet). The form field student is not XML — it comes from the request, like a name written on today’s token.

Easy mistake

Copying the mall name as init-param into every servlet. One change would need ten XML edits. Context exists so you change it once.

Real-life examples (short recap)

Mall / hospital name = ServletContext

Every bill can print the same mall name. Change it once in web.xml and every servlet sees the new name. That is context-param.

One shop’s manager stamp = ServletConfig

Shop A has manager “Student Name”. Shop B is another program. Those values must not leak. That is init-param.

Hotel vs room

Hotel name is shared (context). Room number / this servlet’s author is private (config).

F) Complete Java + complete XML — every line explained

import java.io.IOException;
import java.io.PrintWriter;
import jakarta.servlet.ServletConfig;             // Per-servlet configuration
import jakarta.servlet.ServletContext;            // Whole-application object
import jakarta.servlet.ServletException;
import jakarta.servlet.http.HttpServlet;
import jakarta.servlet.http.HttpServletRequest;
import jakarta.servlet.http.HttpServletResponse;

public class ConfigContextServlet extends HttpServlet {

    @Override
    protected void doGet(HttpServletRequest request, HttpServletResponse response)
            throws ServletException, IOException {
        show(request, response);                  // GET from Execute / address bar
    }

    @Override
    protected void doPost(HttpServletRequest request, HttpServletResponse response)
            throws ServletException, IOException {
        show(request, response);                  // Same output if a form posts here
    }

    private void show(HttpServletRequest request, HttpServletResponse response) throws IOException {
        ServletConfig config = getServletConfig();     // THIS servlet's init-param
        ServletContext context = getServletContext();  // Shared context-param
        response.setContentType("text/html");
        PrintWriter out = response.getWriter();
        out.println("<h2>" + request.getMethod() + "</h2>");
        out.println("<p>collegeName (context) = " + context.getInitParameter("collegeName") + "</p>");
        out.println("<p>author (config) = " + config.getInitParameter("author") + "</p>");
        out.println("<p>student = " + request.getParameter("student") + "</p>"); // Form field, not XML
        out.println("<p><a href='configcontext.html'>Back</a></p>");
    }
}
