Problem statement (mini-project): Develop a student login portal for Walchand Institute of Technology, Solapur on Apache Tomcat 11. The student submits a login form using HTTP POST (user java, password servlet). On success the server must (1) store the user name in HttpSession, (2) remember the display name in a cookie for seven days (never the password), and (3) forward to Welcome so the address bar stays /CapstoneLogin. On a wrong password the same response must include the login form again with an error. Logout must invalidate the session and delete the remember cookie. Submit complete Java for CapstoneLogin, CapstoneWelcome and CapstoneLogout, plus the complete web.xml mappings. Do not mix Cookie1 or NotesSessionLogin into this project.

What the student actually does

  1. Open Execute. Type user java and password servlet. Click Login (POST).
  2. Success page: Welcome java. Address bar still shows /CapstoneLogin because of forward.
  3. Refresh Welcome later: session still has the name (HttpSession).
  4. Open login again later: the user box may already show java (remember cookie).
  5. Click Logout: session is invalidated, cookie is removed, form comes back empty.
  6. Try a wrong password: error message + the same form is included (include, not forward).

What each class does

ClassReal job
CapstoneLoginReads the filled form. Checks java/servlet. On success: session + cookie + forward.
CapstoneWelcomeReads session. If missing, send back to the form. Shows Welcome + Logout.
CapstoneLogoutinvalidate() session and delete remember cookie, then go back to the form.
Check yourself: After a correct login, is the password in the address bar? It should not be (POST body). After logout, does Welcome still greet you? It should not (session cleared).
