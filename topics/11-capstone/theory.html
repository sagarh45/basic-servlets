11. Capstone Mini Project - Student Login App

Theory Lab Setup Index
Verified for Apache Tomcat 11.0.24 (Jakarta EE 11 / Servlet 6.1) + JDK 21+
Every program uses jakarta.servlet.* only. See Lab Setup.

This page is theory only: meaning, real-life examples, diagrams, functions (syntax + use + example) and complete code. Copy the journal problem statement from the ICA Practicals tab or from the program Source page.

A) Concept in simple English

The capstone is a tiny Gmail-style login app. Correct login (java / servlet) keeps you signed in (session), optionally remembers the display name on this PC (cookie, never the password), shows Welcome without changing the URL (forward), shows the form again on a wrong password (include), and logs out cleanly (invalidate + delete cookie).

The capstone joins earlier topics into one login app on Tomcat 11:

  • POST form — login and password (do not use GET for password)
  • HttpSession — store username after success
  • Cookie — remember the login name (not the password)
  • forward — success to CapstoneWelcome (same request)
  • include — fail, show capstone.html again
  • invalidate + setMaxAge(0) — logout

Picture it from daily life

One-line rule: Mini Instagram / Gmail: POST login, hotel guest file (session), optional name sticker (cookie), kitchen on success (forward), same form on failure (include), throw the file away on logout.

The story (one Gmail visit, start to finish)

You open Gmail on a cafe laptop.

  1. You type login and password — POST, never GET, so servlet is not in the address bar.
  2. Correct (java / servlet) — Reception opens a file (HttpSession) and writes username. If you ticked remember name, a sticker is put on the browser (cookie, not the password). The waiter walks the slip to Welcome (forward). You may still see the login URL — that is a viva point: forward does not change the bar.
  3. Wrong password — Nobody opens Welcome. The app stamps “error” and shows the same form (include capstone.html).
  4. Logout — File destroyed (invalidate) and sticker peeled (setMaxAge(0)). The next person on that laptop is not you.

Do not paste Cookie1 or NotesSessionLogin into this project. Those are other experiments. This app has its own three classes: CapstoneLogin, CapstoneWelcome, CapstoneLogout.

Internet banking (teaching analogy only)

Wrong PIN: same page with an error (include). Correct PIN: dashboard (forward or redirect depending on PRG). Logout: session dead. This lab uses forward on success so you can still see the original URL — a viva point.

F) Complete Java programs — every line explained

import java.io.IOException;
import java.io.PrintWriter;
import jakarta.servlet.RequestDispatcher;
import jakarta.servlet.ServletException;
import jakarta.servlet.http.Cookie;
import jakarta.servlet.http.HttpServlet;
import jakarta.servlet.http.HttpServletRequest;
import jakarta.servlet.http.HttpServletResponse;
import jakarta.servlet.http.HttpSession;

public class CapstoneLogin extends HttpServlet {

    @Override
    protected void doGet(HttpServletRequest request, HttpServletResponse response)
            throws ServletException, IOException {
        response.sendRedirect("capstone.html");           // Typing the servlet URL shows the form
    }

    @Override
    protected void doPost(HttpServletRequest request, HttpServletResponse response)
            throws ServletException, IOException {        // Form method=post
        String login = request.getParameter("login");
        String pwd = request.getParameter("pwd");
        if (login != null && pwd != null
                && login.equals("java") && pwd.equals("servlet")) {
            HttpSession session = request.getSession(true);     // Server-side login
            session.setAttribute("username", login);
            Cookie remember = new Cookie("remember", login);    // Display name ONLY
            remember.setMaxAge(60 * 60 * 24 * 7);               // 7 days
            response.addCookie(remember);
            request.getRequestDispatcher("CapstoneWelcome").forward(request, response); // URL stays
        } else {
            response.setContentType("text/html");
            PrintWriter out = response.getWriter();
            out.println("<p>Incorrect Login ID / Password</p>");
            RequestDispatcher rd = request.getRequestDispatcher("/capstone.html");
            rd.include(request, response);                      // Error + form on same response
        }
    }
}
public class CapstoneWelcome extends HttpServlet {
    @Override
    protected void doPost(HttpServletRequest request, HttpServletResponse response)
            throws ServletException, IOException { show(request, response); } // After forward
    @Override
    protected void doGet(HttpServletRequest request, HttpServletResponse response)
            throws ServletException, IOException { show(request, response); }

    private void show(HttpServletRequest request, HttpServletResponse response) throws IOException {
        HttpSession session = request.getSession(false);
        if (session == null || session.getAttribute("username") == null) {
            response.sendRedirect("capstone.html");             // Block direct access
            return;
        }
        response.setContentType("text/html");
        PrintWriter out = response.getWriter();
        out.println("<h1>Welcome " + session.getAttribute("username") + "</h1>");
        out.println("<p><a href='CapstoneLogout'>Logout</a></p>");
    }
}
public class CapstoneLogout extends HttpServlet {
    @Override
    protected void doGet(HttpServletRequest request, HttpServletResponse response)
            throws ServletException, IOException {
        HttpSession session = request.getSession(false);
        if (session != null) { session.invalidate(); }          // Clear server login
        Cookie del = new Cookie("remember", "");
        del.setMaxAge(0);                                       // Clear remember cookie
        response.addCookie(del);
        response.sendRedirect("capstone.html");                 // Back to empty form
    }
}
