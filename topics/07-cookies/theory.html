7. Session Management - Cookies

Theory Lab Setup Index
Verified for Apache Tomcat 11.0.24 (Jakarta EE 11 / Servlet 6.1) + JDK 21+
Every program uses jakarta.servlet.* only. See Lab Setup.

This page is theory only: meaning, real-life examples, diagrams, functions (syntax + use + example) and complete code. Copy the journal problem statement from the ICA Practicals tab or from the program Source page.

A) Concept in simple English

HTTP is stateless. After one response, Tomcat forgets the browser. YouTube still says “Continue as Rahul” and remembers the last video because the browser kept small stickers (cookies). You must never store a password in a cookie in this lab.

HTTP is stateless. After one response, Tomcat forgets the browser unless you store something.

A cookie is a small name=value stored by the browser and sent back on later requests in the Cookie header.

This lab stores display name in cookie user and last watched video in cookie lastVideo. Do not store passwords in cookies.

Picture it from daily life

One-line rule: A cookie is a small name-sticker the browser keeps (like a luggage tag on your bag). Tomcat does not remember you unless that sticker comes back. Never write a password on the sticker.

The story (YouTube “Remember me” + last watched)

HTTP is forgetful. After one answer, the shop forgets who stood at the counter. That is why a website feels “new” on every click unless we store something.

You type your display name on a shared cafe laptop and click Remember me. Next visit, the same browser says Continue as Rahul and opens Home with last watched Java Servlets. The name was not stored in Tomcat as a login session. It was stored as stickers on that browser: cookie user=Rahul and cookie lastVideo=Java.

  1. Create (Cookie1) — Remember me writes sticker user and hands it to the browser (addCookie). Password is never stored.
  2. Read + add (Cookie2) — Home greets you from cookie user and saves last watched lastVideo=Java (like YouTube remembers the last video).
  3. List (Cookie3) — Account settings loops getCookies() and prints every sticker on this laptop.
  4. Delete (CookieDelete) — “Forget me on this device” sends sticker user with age 0. The browser throws it away. Exam answer: setMaxAge(0).

Gmail “Stay signed in” and Amazon “remember me” are the same idea, with more security. This lab only stores a display name and a last-watched title.

What you will see

After Cookie1, DevTools → Application → Cookies shows user. Cookie2 greets Rahul and adds lastVideo. Cookie3 lists both. After Forget me, Cookie3 should not find user.

Easy mistake

Saying “cookie is stored in Tomcat.” It lives in the browser. Restart Tomcat and the cookie can still be there. Close that browser profile and it may be gone.

Real-life examples (short recap)

Remember my name on this browser (YouTube)

You type display name Rahul. Next visit the site says Continue as Rahul. Cookie user lives in the browser profile, not in Tomcat memory.

Last watched video

YouTube Home remembers the last video. Cookie2 saves lastVideo=Java. Cookie3 lists it under Account cookies.

Gmail / Amazon “remember me”

The site stores a token or display name. Real banks use HttpOnly secure cookies; this lab stores only a display name and a last-watched title.

Forget me on this device

YouTube “Sign out of this browser” must delete cookie user. setMaxAge(0) is the exam answer for delete.

B) When to use cookies

Use cookies whenDo not use cookies when
Remember a display name, theme, last city (non-secret)Password, marks, bank data
You need data on the next visit even after the tab closed (setMaxAge > 0)You need data only on the server (use HttpSession)
The browser may send the value back automaticallyThe student must not be able to change the value (use HttpSession)

Create Remember me in Cookie1. Read + last watched in Cookie2. List in Cookie3. Forget me with same name + setMaxAge(0) in CookieDelete.

D) Full syntax

import jakarta.servlet.http.Cookie;

// CREATE
Cookie c = new Cookie("user", login);
response.addCookie(c);

// READ
Cookie[] arr = request.getCookies();
if (arr != null) {
  for (Cookie x : arr) {
    if ("user".equals(x.getName())) {
      out.println(x.getValue());
    }
  }
}

// DELETE
Cookie del = new Cookie("user", "");
del.setMaxAge(0);
response.addCookie(del);

new Cookie("user", login)Name and value. Avoid spaces in the value.
addCookie(c)Sends Set-Cookie to the browser.
getCookies()May return null if the browser sent none.
setMaxAge(0)Delete. Negative = session cookie (until browser closes). Positive = seconds to live.

E) Functions — syntax, use and example

Each function below is the Java for the daily-life story above. Read the meaning, then the syntax, then the lab row.

A cookie lives in the browser. Tomcat forgets the browser; the cookie comes back on the next request.

1. Function: new Cookie

Simple meaning: Creates a small name=value pair. Name in this lab must be user so Cookie2 can find it.

Full syntax:

Cookie c = new Cookie("user", login);
ItemSimple English
Parametersname (no spaces), value (display name, not a password)
ReturnsCookie object (not yet sent)
When to use (USE)Remember-me display name.
Lab exampleCookie1: new Cookie("user", "Rahul")
Common mistakeStoring the password in a cookie.

2. Function: setMaxAge

Simple meaning: Lifetime in seconds. Positive = keep after the tab closes. 0 = delete.

Full syntax:

c.setMaxAge(60 * 60);   // 1 hour
c.setMaxAge(0);          // delete now
ItemSimple English
Parametersseconds (int)
Returnsvoid
When to use (USE)Persistent Remember me, or Forget me on this device.
Lab exampleCookieDelete uses 0 so the browser drops cookie user (YouTube Sign out of this browser).
Common mistakeCalling setMaxAge after addCookie on a different object — the browser never sees it.

3. Function: addCookie

Simple meaning: Sends Set-Cookie to the browser. Prefer this before writing the HTML body.

Full syntax:

response.addCookie(c);
ItemSimple English
Parametersthe Cookie you built
Returnsvoid
When to use (USE)After you create or delete a cookie.
Lab exampleCookie1 addCookie then prints Continue as Rahul and a link to Home.
Common mistakeOnly creating the Cookie in memory and never calling addCookie.

4. Function: getCookies

Simple meaning: Array of cookies the browser sent. May be null if none.

Full syntax:

Cookie[] arr = request.getCookies();
if (arr != null) { ... }
ItemSimple English
Parametersnone
ReturnsCookie[] or null
When to use (USE)Read the saved name on the next page.
Lab exampleCookie2 loops and prints user = Rahul.
Common mistakeUsing arr.length without the null check — NullPointerException.

5. Function: getName / getValue

Simple meaning: Read one cookie’s name and value in the loop.

Full syntax:

arr[i].getName()
arr[i].getValue()
ItemSimple English

ReturnsString

Lab exampleif ("user".equals(arr[i].getName())) print the value.

F) Complete Java programs — every line explained

import java.io.*;                                // IOException, PrintWriter
import jakarta.servlet.*;                        // ServletException
import jakarta.servlet.http.*;                   // HttpServlet, Cookie, request, response

public class Cookie1 extends HttpServlet {       // Remember me — CREATE cookie user

    public void doPost(HttpServletRequest request, HttpServletResponse response)
            throws ServletException, IOException {
        String login = request.getParameter("login");  // Display name from the form
        if (login == null || login.isEmpty()) {
            login = "guest";                     // Safe default for empty box
        }
        Cookie c = new Cookie("user", login);    // Name must be "user" for later readers
        c.setMaxAge(60 * 60);                    // 1 hour in seconds (persistent)
        response.addCookie(c);                   // Sends Set-Cookie to the browser
        response.setContentType("text/html");
        PrintWriter out = response.getWriter();
        out.println("<h2>Continue as " + login + "</h2>");
        out.println("<p>This browser saved your name (cookie user=" + login + "), like YouTube Remember me.</p>");
        out.println("<p>Password is not stored.</p>");
        out.println("<p><a href='Cookie2'>Open Home (last watched)</a> | <a href='CookieDelete'>Forget me on this device</a></p>");
        out.println("<p><a href='cookie.html'>Back</a></p>");
    }
}
public class Cookie2 extends HttpServlet {       // Home — READ cookies + last watched
    public void doGet(HttpServletRequest request, HttpServletResponse response)
            throws ServletException, IOException {
        response.setContentType("text/html");
        PrintWriter out = response.getWriter();
        String display = "guest";
        out.println("<html><body><h2>Home — last watched</h2>");
        Cookie[] arr = request.getCookies();     // May be null if browser sent none
        if (arr != null) {
            for (int i = 0; i < arr.length; i++) {
                if ("user".equals(arr[i].getName())) {
                    display = arr[i].getValue(); // Continue as ...
                }
                out.println(arr[i].getName() + " = " + arr[i].getValue() + "<br>");
            }
        } else {
            out.println("<p>No cookies yet. Stay signed in first.</p>");
        }
        out.println("<p>Welcome back " + display + "</p>");
        Cookie c2 = new Cookie("lastVideo", "Java");
        response.addCookie(c2);                  // Like YouTube last watched
        out.println("<p>Saved last watched: Java Servlets (cookie lastVideo=Java), like YouTube remembers the last video.</p>");
        out.println("<p><a href='Cookie3'>Account cookies</a></p>");
        out.println("</body></html>");
    }
}
public class Cookie3 extends HttpServlet {       // Account settings — LIST cookies
    public void doGet(HttpServletRequest request, HttpServletResponse response)
            throws ServletException, IOException {
        response.setContentType("text/html");
        PrintWriter out = response.getWriter();
        out.println("<html><body><h2>Account — cookies on this browser</h2>");
        Cookie[] arr = request.getCookies();
        if (arr != null) {
            for (int i = 0; i < arr.length; i++) {
                out.println(arr[i].getName() + " = " + arr[i].getValue() + "<br>");
            }
        } else {
            out.println("<p>No cookies.</p>");
        }
        out.println("<p><a href='CookieDelete'>Forget me on this device</a></p>");
        out.println("</body></html>");
    }
}
public class CookieDelete extends HttpServlet {  // Forget me — DELETE cookie user
    public void doGet(HttpServletRequest request, HttpServletResponse response)
            throws ServletException, IOException {
        response.setContentType("text/html");
        Cookie del = new Cookie("user", "");     // Same NAME as the cookie to remove
        del.setMaxAge(0);                        // 0 seconds = delete now
        response.addCookie(del);                 // Browser drops cookie "user"
        PrintWriter out = response.getWriter();
        out.println("<h2>Forgot you on this device</h2>");
        out.println("<p>Cookie user was deleted (setMaxAge(0)), like YouTube Sign out of this browser.</p>");
        out.println("<p>lastVideo may still be here until you clear site data.</p>");
        out.println("<p><a href='Cookie3'>Check account cookies</a></p>");
    }
}
