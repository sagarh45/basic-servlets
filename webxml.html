Complete web.xml (every block explained)

File location: WEB-INF/web.xml. This is the full deployment descriptor used by Apache Tomcat 11.0.24 (Jakarta EE 11 / Servlet 6.1). Copy this entire file into the ICA journal when the teacher asks for complete XML. Each <servlet> registers a Java class. Each <servlet-mapping> binds a URL. The two <servlet-name> values must match exactly.

Rules for this file

Header must use Jakarta namespace and version="6.1" — not Java EE / javax / web-app 2.5.

context-param is application-wide (college letterhead). init-param sits inside one servlet (clerk stamp).

url-pattern is the path after /basic-servlets. Example: /hello means http://localhost:8080/basic-servlets/hello.
