Lab Setup: Apache Tomcat 11.0.24 (latest)

This lab is written for Apache Tomcat 11.0.24 (latest Tomcat as of July 2026).

Tomcat 11 implements Jakarta EE 11 / Servlet 6.1. Every program uses jakarta.servlet.* (not javax.servlet.*).

After you install Tomcat 11 and deploy this folder, open: http://localhost:8080/basic-servlets/

2) How to install Tomcat 11 on Windows

  1. Install JDK 21 or later. Confirm in Command Prompt: java -version shows 21 or higher.
  2. Open Tomcat 11 download page.
  3. Under 11.0.24 download the Windows installer apache-tomcat-11.0.24.exe or the zip apache-tomcat-11.0.24-windows-x64.zip.
  4. Installer typical folder: C:\Program Files\Apache Software Foundation\Tomcat 11.0\
  5. If you use the zip, extract it (example C:\apache-tomcat-11.0.24) and set environment variable CATALINA_HOME to that folder.
  6. Start Tomcat: bin\startup.bat or the Start Menu shortcut.
  7. Test: http://localhost:8080/ should show the Tomcat home page.

If port 8080 is already used by old Tomcat 9, stop Tomcat 9 first (Windows Services, or bin\shutdown.bat in the Tomcat 9 folder).

  1. Browser sends an HTTP request (GET or POST, etc.).
  2. URL starts with /basic-servlets because the folder name inside Tomcat webapps is basic-servlets.
  3. Tomcat 11 is the servlet container. It loads classes from WEB-INF/classes.
  4. web.xml maps a URL pattern (example /httpmethods) to a Java class (example HttpMethodsServlet).
  5. Tomcat calls doGet / doPost / ... on that class.
  6. The servlet writes HTML with PrintWriter. The browser shows the page.

5) How to compile and deploy this lab

  1. Copy this whole folder into Tomcat webapps\basic-servlets (folder name must be basic-servlets).
  2. Full Java sources are in src\. Compiled classes are already in WEB-INF\classes. If you edit Java, run compile.bat (needs JDK 21+ and Tomcat 11 lib\servlet-api.jar).
  3. Optional: run deploy-full.bat to copy into C:\Program Files\Apache Software Foundation\Tomcat 11.0\webapps\basic-servlets\ (or %CATALINA_HOME%\webapps\basic-servlets).
  4. Start Tomcat 11 if it is not running.
  5. Open http://localhost:8080/basic-servlets/
  6. If the browser shows an old page, press Ctrl+F5. If a servlet still looks old, restart Tomcat once.

Login for session demos: user java / password servlet (or as shown on that Execute page).
