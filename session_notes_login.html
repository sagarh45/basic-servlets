Problem statement

Title: HttpSession login, welcome and logout

Store the user name on the server (session), not only in the browser. Login is java / servlet.

What you must do:

  1. POST login java and password servlet. The server stores the name and opens Welcome.
  2. Welcome must print Welcome java and a Logout link.
  3. Click Logout. Session is cleared and the login form comes back. Wrong password prints Wrong login. Use java / servlet.

Sample output (same HTML Tomcat prints at http://localhost:8080/basic-servlets/...):

Welcome java
Logout
