What this project does

MyMail is a small Gmail-like site. HTTP forgets you after each click, so we store a name in four ways. Then we join them in one portal.

  1. Remember me (cookie) — browser keeps user=Rahul. Home greets you. Forget me uses setMaxAge(0).
  2. Gmail login (HttpSession) — name lives on the server. Welcome then Logout.
  3. Cookies off (URL rewriting) — ids travel in the next-page link.
  4. Hidden id — form posts session_id=054 you did not type. View Source still shows it.
  5. Full portal — success: session + cookie + forward (URL stays /CapstoneLogin). Wrong password: include the form. Logout: invalidate + cookie maxAge 0.
