Small project: MyMail + PayNow

One HTML page. Three Java classes for forward and redirect. Include uses two more classes and runs from the button below. Watch the address bar every time.

ICA journal Run project Source

What this project does

Forward = open a Gmail mail in the same tab. Address bar stays /forward. The PASS message travels in a request attribute.

Redirect = PayNow sends you to the bank. Address bar changes to /target. Attributes are lost.

Include = MyMail page pastes a help footer into this page, then prints a green line. Address bar stays /include.

  1. Open mail (forward). URL stays /forward. Page shows PASS for Rahul.
  2. Pay now (redirect). URL becomes /target?from=RedirectServlet&student=Rahul.
  3. Open page with footer (include). URL stays /include. The green line after include still runs.
